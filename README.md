##  Key Features & Innovations (工夫した点)

本プロジェクトでは、ノイズが多く個人差の激しいEEG（脳波）データから高い汎化性能で特徴を抽出するため、以下のアーキテクチャ設計および学習戦略を採用しています。

### 1. MAE (Masked Autoencoder) と Conformerの融合アーキテクチャ
EEG信号における空間的（電極間）および時間的依存関係を同時に捉えるため、CNNの局所的特徴抽出とTransformerの大域的文脈理解の利点を併せ持つ**Conformer**をエンコーダーに採用しました。さらに、脳波のアノテーションデータが限られているという課題に対し、MAEによる自己教師あり学習（表現学習）を事前学習として導入。入力系列の大部分（60%）をマスクし、残りのパッチから全体を復元するタスクを解かせることで、ラベルに依存しない脳波の堅牢な構造的特徴を獲得させています。

### 2. 被験者間の個人差を吸収する Subject Embedding
脳波には被験者ごとの強いバイアス（頭蓋骨の厚さや電極位置の微小なズレによる個人差）が存在します。これをモデル側で吸収するため、単純な波形入力だけでなく、被験者IDをベクトル化する `Subject Embedding` 層を設計しました。これを入力特徴量に加算（Conditioning）することで、モデルが被験者固有のノイズに過適合（オーバーフィッティング）することを防ぎ、未見のデータに対する汎化性を高めています。

### 3. 破滅的忘却（Catastrophic Forgetting）を防ぐ2段階ファインチューニング
事前学習で獲得した強力なエンコーダーの重みが、下流の分類タスクへ移行する際、ランダム初期化された分類ヘッドからの巨大な初期勾配によって破壊されるのを防ぐため、学習プロセスを厳密に2段階に分割しています。
* **Phase 1 (Linear Probing):** エンコーダーの重みを完全に凍結（Freeze）し、分類ヘッド周辺のみをウォームアップ学習。
* **Phase 2 (Full Fine-tuning):** 適切な学習率スケジューラ（ReduceLROnPlateau）を用い、非常に小さな学習率でモデル全体の微調整を実行。

### 4. EEG特化型のデータ拡張とMixupによる正則化
波形の意味的構造を破壊しない範囲で、物理的・生理学的なノイズを模倣した独自のデータ拡張処理を実装しました。
* **Time Masking / Channel Dropout:** 瞬きによる一時的な欠損や、特定電極の接触不良を模倣。
* **Shift / Noise / Scale:** 位相のズレや振幅の変化に対する不変性を獲得。
さらに、決定境界を滑らかにしモデルの過信を防ぐため **Mixup** を適用し、ノイズの多いテストデータに対する堅牢性を大幅に向上させています。

### 5. TTA (Test-Time Augmentation) と検証スコアに基づく重み付きアンサンブル
推論時にも微小なノイズ付与や時間軸のシフトを伴うTTA（4パターン）を実行し、予測確率の分散を平滑化しました。最終的な推論結果は、単一のモデルに依存せず、複数のアーキテクチャ（MAE, Conformer, Hybrid等）が出力したロジットに対して、それぞれの検証スコア（Validation Accuracy）に比例した重み付けを行うWeighted Ensemble（加重平均）によって算出しています。
